# Style guide: Verdict Margin

Decisive and composed, with editorial typography and a bold canvas that keeps the argument in focus.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #07504A | ground |
| `--surface` | #123E3B | cards and panels |
| `--fg` | #FFFFFF | primary text |
| `--muted` | #D5E6E1 | secondary text |
| `--accent` | #FFD48A | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #9DE0CF | supporting color, used sparingly |
| `--rule` | #769F99 | hairlines and borders |

## Type

- Display: grotesk stack, weight 700, normal tracking, regular scale.
- Body: serif stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 8px; borders: hairline; shadows: none.
- Background motif: none. Density: balanced.

## Rules

- Every substantive slide opens with a sentence-length action title that states its conclusion, not its topic.
- Reserve a narrow left margin for a section number and a verdict of no more than six words; keep evidence in the remaining width.
- Use the saturated teal ground on every slide; use dark-teal surfaces only where a chart, comparison, or repeated item needs separation.
- Set headlines in bold grotesk and explanatory copy in serif; do not use more than two type families.
- Use amber for the recommended option or decisive number only; do not color every data series amber.
- Give every quantitative exhibit a unit, a time basis, and a compact source or assumption note.
- Limit each slide to one primary exhibit and no more than three supporting points.
