# Style guide: Split Canvas Reveal

A cool, precise studio canvas turns one product interaction into a bold, dimensional reveal.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #f4f7f8 | ground |
| `--surface` | #ffffff | cards and panels |
| `--fg` | #101719 | primary text |
| `--muted` | #465459 | secondary text |
| `--accent` | #b42646 | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #087e83 | supporting color, used sparingly |
| `--rule` | #bac6c9 | hairlines and borders |

## Type

- Display: sans stack, weight 800, uppercase, tight tracking, oversized scale.
- Body: mono stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 24px; borders: hairline; shadows: soft.
- Background motif: noise. Density: airy.

## Rules

- Keep the canvas paper-white or ice-gray; reserve dark studio panels for device surfaces only.
- Open on one short uppercase hook, no more than six words, with generous empty space.
- Reveal the interface through a single perspective device slab, never a collage of floating screens.
- Use the crimson and teal split only to distinguish before and after states; do not mix both within one interface panel.
- Make the oversized cursor perform one legible action that directly demonstrates the product promise.
- Use monospace for labels, timestamps, and evidence annotations; use sans for headlines and product copy.
- Show only fictional, plausible product UI and evidence supplied or explicitly approved by the user.
- End on a quiet brand lockup and one direct call to action, held long enough to read.
