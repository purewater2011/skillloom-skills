# Style guide: Constellation Ledger

A dark research instrument where evidence, relationships, and project decisions form a precise illuminated constellation.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #0b0d12 | ground |
| `--surface` | #151a22 | cards and panels |
| `--fg` | #f4f6f8 | primary text |
| `--muted` | #b4beca | secondary text |
| `--accent` | #7ee7c8 | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #8bb8ff | supporting color, used sparingly |
| `--rule` | #33404d | hairlines and borders |

## Type

- Display: condensed stack, weight 800, uppercase, tight tracking, oversized scale.
- Body: sans stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 8px; borders: hairline; shadows: none.
- Background motif: lines. Density: balanced.

## Rules

- Set major headlines in uppercase condensed at 800 weight, with six words or fewer whenever possible.
- Use the near-black ground for the canvas, mint for sourced facts, and blue for relationship lines and dependency labels.
- Build hierarchy from knowledge blocks, hairline connectors, and citation labels, not decorative illustrations or gradients.
- Attach a source marker such as [S1] to every substantive factual claim, statistic, milestone, risk, or interpretation.
- Keep body copy in a calm sans serif with generous line height; never use all caps for paragraphs or citations.
- Use 8px corners, consistent inset spacing, and no floating pill clusters except for compact status tags.
- Treat empty space as separation between evidence clusters, with readable connector paths and labels that never cover content.
