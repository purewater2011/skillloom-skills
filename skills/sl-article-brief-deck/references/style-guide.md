# Style guide: Gridline Article Brief

A disciplined editorial system that makes evidence easy to scan, compare, teach, and act on.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #FFFFFF | ground |
| `--surface` | #F3F3F0 | cards and panels |
| `--fg` | #111111 | primary text |
| `--muted` | #505050 | secondary text |
| `--accent` | #D9362B | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #1F5A8A | supporting color, used sparingly |
| `--rule` | #B8B8B2 | hairlines and borders |

## Type

- Display: didone stack, weight 700, tight tracking, oversized scale.
- Body: grotesk stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 0px; borders: hairline; shadows: none.
- Background motif: grid. Density: balanced.

## Rules

- Use a visible 12-column grid with aligned edges, consistent gutters, and generous outer margins.
- Set action titles as sentence case Didone headlines; keep them to one clear claim or decision.
- Use pure white as the ground, near-black for primary text, and red only for emphasis, status, or key evidence.
- Keep cards square with hairline rules; never use floating shadows, rounded containers, or decorative gradients.
- Pair every statistic or claim with a source cue, qualification, or interpretation in nearby supporting text.
- Use one dominant visual structure per slide and leave at least one full column of breathing room.
- Alternate dense evidence slides with lighter framing slides so the narrative remains teachable and easy to present.
