# Style guide: Signal Blocks

Precise and energetic, like a product story assembled from a visible system of modular parts.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #101417 | ground |
| `--surface` | #222B30 | cards and panels |
| `--fg` | #F7FAF8 | primary text |
| `--muted` | #B8C5C8 | secondary text |
| `--accent` | #70E6BD | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #F4BB68 | supporting color, used sparingly |
| `--rule` | #536066 | hairlines and borders |

## Type

- Display: condensed stack, weight 800, uppercase, normal tracking, oversized scale.
- Body: sans stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 14px; borders: hairline; shadows: none.
- Background motif: blocks. Density: balanced.

## Rules

- Build every slide on a consistent 12-column grid with aligned block edges.
- Use uppercase condensed action headlines of no more than 12 words; keep supporting copy in sentence case.
- Use blocks for categories, stages, comparisons, or quantities, never as random decoration.
- Construct charts, diagrams, dividers, and labels with editable HTML, CSS, and SVG; do not flatten slides into images.
- Use mint for primary emphasis and amber for secondary contrast; reserve both for important data or decisions.
- Keep body copy to 28 words or fewer per content region and use no more than four regions per slide.
- Keep slide numbers and section labels aligned consistently on every slide except the title.
