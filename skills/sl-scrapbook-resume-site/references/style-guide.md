# Style guide: Cobalt Field Notes

A carefully assembled creative dossier, tactile and expressive without obscuring professional credentials.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #151719 | ground |
| `--surface` | #282C2F | cards and panels |
| `--fg` | #F8F4E9 | primary text |
| `--muted` | #BCC5C6 | secondary text |
| `--accent` | #83A5FF | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #EADDBB | supporting color, used sparingly |
| `--rule` | #626A6D | hairlines and borders |

## Type

- Display: rounded stack, weight 800, normal tracking, regular scale.
- Body: rounded stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 14px; borders: hairline; shadows: hard.
- Background motif: blocks. Density: balanced.

## Rules

- Keep the page canvas near-black; use cream only for bounded paper inserts, labels, or project imagery.
- Place a lanyard-inspired identity badge in the hero with the person's name, role, location, and availability.
- Use cobalt as a flat highlighter behind short phrases and small marks, never behind paragraph-length copy.
- Give portfolio entries distinct paper-like blocks with a title, discipline, year, and a clear link to the work.
- Keep all essential resume facts in selectable HTML text; decorative tape, clips, and paper edges must not carry information.
- Use ink-dark text on cream inserts and cream text on dark surfaces; do not place cream text over cobalt highlights.
- Limit rotated scrapbook elements to small labels and decorative pieces; body copy and navigation stay level.
- At narrow widths, stack collage blocks in reading order without overlap or horizontal scrolling.
