# Style guide: Quiet Beacon

A calm, minimal dark canvas gives a practical software product room to feel clear, capable, and quietly distinctive.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #111315 | ground |
| `--surface` | #202326 | cards and panels |
| `--fg` | #F5F7F6 | primary text |
| `--muted` | #BBC3BF | secondary text |
| `--accent` | #B7F36B | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #8EDFC8 | supporting color, used sparingly |
| `--rule` | #414744 | hairlines and borders |

## Type

- Display: humanist stack, weight 700, tight tracking, regular scale.
- Body: humanist stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 14px; borders: hairline; shadows: soft.
- Background motif: blocks. Density: airy.

## Rules

- Keep the page on a near-black charcoal ground; use lighter charcoal only for distinct interface surfaces.
- Use humanist system fonts for all text and preserve a clear difference between headline and body scale.
- Use the lime accent for primary actions, small status details, and no more than one short headline phrase.
- Keep body copy and muted text high-contrast; never lower text contrast to simulate a subdued aesthetic.
- Use generous vertical spacing and short copy blocks; each section should make one clear point.
- Use 14px-radius surfaces with hairline borders; avoid nested cards and decorative floating panels.
- Use glow only as a restrained highlight around a real interface element, never as a page-wide background effect.
