# Style guide: Loop in Motion

Bright, assured, and learner-centered, with the energy of a workshop and the discipline of an executive report.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #064936 | ground |
| `--surface` | #12634F | cards and panels |
| `--fg` | #FFFFFF | primary text |
| `--muted` | #D4EFE5 | secondary text |
| `--accent` | #FFE16A | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #FFB49A | supporting color, used sparingly |
| `--rule` | #79B9A4 | hairlines and borders |

## Type

- Display: mono stack, weight 700, normal tracking, regular scale.
- Body: sans stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 8px; borders: hairline; shadows: none.
- Background motif: gradient. Density: balanced.

## Rules

- Keep the green canvas visible; use gradients only within the loop motif and supporting bands.
- Use one recurring four-stage loop labeled Notice, Try, Feedback, and Revise; highlight the stage relevant to each slide.
- Set every slide title as a full-sentence action title in bold mono type, with no more than two lines.
- Place learner-facing examples in 8px-radius cards; limit each card to one heading and two short lines of body copy.
- Use yellow for the active loop stage and key takeaway, and peach only for a contrasting risk or previous state.
- Show chart units, cohort definitions, and whether figures are illustrative directly beside any numeric claim.
- Reserve clear text-free space around the loop graphic; never place body copy over a gradient.
