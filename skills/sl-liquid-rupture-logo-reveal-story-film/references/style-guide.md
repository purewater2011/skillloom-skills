# Style guide: Paper Rupture

Warm editorial calm builds into a precise, tactile burst of refracted colour and resolved identity.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #F5F0E8 | ground |
| `--surface` | #FFFDF8 | cards and panels |
| `--fg` | #1E1A17 | primary text |
| `--muted` | #5B5148 | secondary text |
| `--accent` | #8F2D56 | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #1B6B68 | supporting color, used sparingly |
| `--rule` | #C9BBAA | hairlines and borders |

## Type

- Display: serif stack, weight 700, tight tracking, oversized scale.
- Body: serif stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: pill (fully rounded buttons, inputs and tags; 28px on cards and panels so text never escapes a curve); borders: hairline; shadows: soft.
- Background motif: paper. Density: airy.

## Rules

- Keep the warm paper ground visible in every scene; never switch to a dark full-bleed background.
- Use one continuous liquid event: colour fields may drift and merge, but only one rupture may expose the final mark.
- Set the reveal wordmark in oversized serif type with tight tracking; never use more than two short lines of supporting copy.
- Build glass-fringe edges with layered translucent shapes and thin rule highlights, not photographic texture or stock imagery.
- Reserve accent burgundy for the rupture and identity lockup; use teal only as a restrained refracted counterpoint.
- Keep scene transitions on slow elastic easing except for the rupture, which must be a brief, decisive snap.
- Maintain generous negative space around the logo so the final frame reads clearly at social-feed scale.
