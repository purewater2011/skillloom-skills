# Style guide: Cinematic Frame Study

Quietly dramatic and tactile, pairing documentary restraint with luminous framed compositions that make each idea feel like a carefully observed scene.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #202a2a | ground |
| `--surface` | #34403e | cards and panels |
| `--fg` | #f4f0e6 | primary text |
| `--muted` | #c3ccc4 | secondary text |
| `--accent` | #d56b4f | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #86a69a | supporting color, used sparingly |
| `--rule` | #71807a | hairlines and borders |

## Type

- Display: grotesk stack, weight 700, uppercase, wide tracking, oversized scale.
- Body: serif stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 4px; borders: hairline; shadows: none.
- Background motif: frame. Density: balanced.

## Rules

- Use a thin rectangular frame or corner mark to anchor every slide; never let the frame become a decorative border around all content.
- Set action titles in uppercase grotesk with wide tracking and keep them to one concise sentence or clause.
- Use serif body copy only for reflective notes, quotations, and captions; keep operational labels in grotesk.
- Reserve terracotta accent for one focal mark, data point, or word per composition; do not use it as a full background.
- Build atmosphere with layered translucent SVG planes, crop lines, and low-contrast contours rather than gradients or stock-photo effects.
- Keep one dominant visual field per slide with generous negative space and no more than four content groups.
- Use hairline rules and muted sage secondary marks to establish sequence, alignment, and editorial rhythm.
- Keep corners at 4px and avoid pills, rounded cards, drop shadows, and ornamental interface chrome.
