# Style guide: Ochre Margin

A crisp publishing review with ink-dark type, cool paper, and measured ochre emphasis.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #F4F6F6 | ground |
| `--surface` | #FFFFFF | cards and panels |
| `--fg` | #202426 | primary text |
| `--muted` | #4D565A | secondary text |
| `--accent` | #8A4D12 | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #315D61 | supporting color, used sparingly |
| `--rule` | #BDC7C9 | hairlines and borders |

## Type

- Display: mono stack, weight 700, uppercase, normal tracking, regular scale.
- Body: sans stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 24px; borders: hairline; shadows: none.
- Background motif: gradient. Density: balanced.

## Rules

- Write every slide headline as a complete, evidence-led sentence; keep it to two lines or fewer.
- Set headlines in uppercase mono and body copy in sans; use condensed uppercase labels only for section markers.
- Reserve ochre for key figures, chart highlights, and short margin markers; never use it for body paragraphs.
- Use a subtle ochre-to-cool-gray gradient only in narrow edge bands or image overlays, never behind dense text.
- Align text, charts, and captions to a consistent editorial column grid with generous outer margins.
- Use 24px rounding only on framed media or data panels; keep page sections and text columns unframed.
- Label every chart with its unit and period, and pair each metric with a plain-language takeaway.
