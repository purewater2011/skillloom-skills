# Style guide: Sage Grid Notes

An observant editorial report, with the discipline of an executive briefing and the energy of a sports analysis spread.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #164C3E | ground |
| `--surface` | #315C50 | cards and panels |
| `--fg` | #FFFFFF | primary text |
| `--muted` | #D8E8DC | secondary text |
| `--accent` | #FFD877 | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #F4B39A | supporting color, used sparingly |
| `--rule` | #91B5A2 | hairlines and borders |

## Type

- Display: serif stack, weight 700, normal tracking, regular scale.
- Body: serif stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 8px; borders: hairline; shadows: none.
- Background motif: grid. Density: balanced.

## Rules

- Use the saturated green canvas on every slide; keep the reference grid subtle enough that it never crosses body text at full opacity.
- Align titles, data, and footnotes to a consistent grid with at least 48 px of outer margin at 1920 x 1080.
- Set each slide title as a complete, evidence-led sentence, normally no longer than 12 words.
- Use serif type for both display and body copy; reserve the yellow accent for key figures, chart emphasis, and small labels.
- Keep panels translucent in appearance through restrained surface color and hairline borders; never blur text behind a panel.
- Label every metric with its unit and reporting period, and distinguish actual results from targets.
- Limit each slide to one primary takeaway and no more than four supporting figures or points.
