# Style guide: Cobalt Dot System

Precise and energetic, with the discipline of an identity guide and the pace of an executive briefing.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #101820 | ground |
| `--surface` | #20303A | cards and panels |
| `--fg` | #F7F9F7 | primary text |
| `--muted` | #BCCBD0 | secondary text |
| `--accent` | #F4DE52 | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #7297FF | supporting color, used sparingly |
| `--rule` | #52646E | hairlines and borders |

## Type

- Display: humanist stack, weight 700, normal tracking, regular scale.
- Body: humanist stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 14px; borders: hairline; shadows: none.
- Background motif: dots. Density: balanced.

## Rules

- Use the near-black ground on every slide; reserve cobalt for geometric fields and lemon for the single primary emphasis.
- Place a small, regularly spaced dot matrix in one consistent corner; never put dots behind body copy or data labels.
- Write every slide heading as a full-sentence action title, with no more than two lines at the chosen deck size.
- Keep chart axes, values, units, and source notes as live HTML text; do not bake data labels into images.
- Use one 14px-radius treatment for framed data panels; leave narrative sections unframed.
- Align headlines, charts, and footer metadata to the same fixed grid across all slides.
- Use lemon on no more than one metric, phrase, or chart series per slide.
