# Style guide: Basalt Beam

A focused developer portfolio where restrained cyan light cuts through a deep basalt canvas to give projects clarity and momentum.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #101416 | ground |
| `--surface` | #1B2224 | cards and panels |
| `--fg` | #F4F7F6 | primary text |
| `--muted` | #B0BDBD | secondary text |
| `--accent` | #59E1E6 | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #9BE9D2 | supporting color, used sparingly |
| `--rule` | #394446 | hairlines and borders |

## Type

- Display: grotesk stack, weight 700, tight tracking, oversized scale.
- Body: sans stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 8px; borders: hairline; shadows: soft.
- Background motif: lines. Density: balanced.

## Rules

- Keep the page canvas near-black basalt; reserve cyan for links, beam accents, focus states, and a few key metrics.
- Use a sans-serif system stack throughout, with bold compact headlines and readable body copy.
- Build project cards as restrained dark surfaces with hairline borders; use a subtle cyan edge glow only on hover or keyboard focus.
- Use thin horizontal rules and occasional diagonal beam lines as the signature motif; never add decorative blobs or heavy gradients.
- Keep headlines to one or two lines on desktop and preserve clear spacing between the hero, project work, and supporting sections.
- Make project titles, roles, dates, technologies, and outcomes scannable without relying on color alone.
- Use motion sparingly for beam reveals and card hover states, and respect reduced-motion preferences.
