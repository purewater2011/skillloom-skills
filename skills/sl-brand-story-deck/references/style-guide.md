# Style guide: Moss & Signal

Grounded, editorial, and confidently modern, with deep muted green fields punctuated by sharp chartreuse blocks.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #3E4C43 | ground |
| `--surface` | #48564C | cards and panels |
| `--fg` | #F7F6EF | primary text |
| `--muted` | #D9DFD9 | secondary text |
| `--accent` | #D8EF72 | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #B7C9BA | supporting color, used sparingly |
| `--rule` | #829087 | hairlines and borders |

## Type

- Display: didone stack, weight 700, normal tracking, oversized scale.
- Body: humanist stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 4px; borders: hairline; shadows: none.
- Background motif: blocks. Density: balanced.

## Rules

- Use large, flat rectangles as the main compositional device; avoid gradients and decorative textures.
- Keep every slide on a deep muted-green ground, with ivory text and chartreuse reserved for emphasis.
- Set headlines in the didone display face and supporting copy in the humanist body face.
- Keep action titles to one clear sentence, ideally under 12 words.
- Use sharp-edged or 4px-radius panels; avoid pill shapes and rounded-card interfaces.
- Use chartreuse blocks for one focal point per slide, not as a background for long paragraphs.
- Maintain generous negative space and align text and blocks to a consistent left edge.
