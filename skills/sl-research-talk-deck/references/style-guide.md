# Style guide: Emberline Research

Calm and human, with warm paper grounds, precise typography, and a restrained luminous emphasis on key evidence.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #F7F2E9 | ground |
| `--surface` | #FFFDF8 | cards and panels |
| `--fg` | #252725 | primary text |
| `--muted` | #55534D | secondary text |
| `--accent` | #813A30 | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #315A51 | supporting color, used sparingly |
| `--rule` | #D6C9B9 | hairlines and borders |

## Type

- Display: slab stack, weight 700, normal tracking, regular scale.
- Body: grotesk stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: pill (fully rounded buttons, inputs and tags; 28px on cards and panels so text never escapes a curve); borders: hairline; shadows: none.
- Background motif: glow. Density: balanced.

## Rules

- Write each slide title as a complete sentence stating its takeaway, with no more than 14 words.
- Set titles in the slab display face and body text in the grotesk face; keep body text at least 24 px on a 1920 x 1080 canvas.
- Use cream as the slide ground and reserve clay accent for findings, chart emphasis, and section markers.
- Apply a faint, contained glow only behind a key figure or finding; never place glow behind paragraph text.
- Use pill shapes only for short labels or figure keys, not for paragraphs or slide titles.
- Label every quantitative chart with units, groups, and a source or illustrative-data note on the same slide.
- Render equations as editable text or MathML, define symbols nearby, and never flatten an equation into an image.
