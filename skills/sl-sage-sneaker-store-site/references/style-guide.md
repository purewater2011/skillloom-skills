# Style guide: Citron Shoebox Grid

Bright and exacting, with fashion-editorial typography and the practical clarity of a well-organized stockroom.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #D8EE35 | ground |
| `--surface` | #FFFEF2 | cards and panels |
| `--fg` | #142219 | primary text |
| `--muted` | #34422B | secondary text |
| `--accent` | #17453B | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #8D292E | supporting color, used sparingly |
| `--rule` | #536332 | hairlines and borders |

## Type

- Display: didone stack, weight 700, normal tracking, regular scale.
- Body: humanist stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 8px; borders: hairline; shadows: none.
- Background motif: grid. Density: dense.

## Rules

- Use citron as the page canvas and ivory for product listings and shopping controls.
- Keep the hero compact: show a clear shoe side profile beside the name, price, and action; let the collection start near the fold.
- Use supplied product photography in the final page; never substitute a large empty panel for an available image.
- If imagery is unavailable, label placeholders as samples and keep them compact; identify every placeholder in the hand-off.
- Align product images, names, prices, and variant details to a consistent shoebox-label grid.
- Use Didone for the hero product name and humanist type for navigation, prices, specifications, and controls.
- Use 8px product-card corners, hairline borders, no shadows, and dark green purchase actions; reserve red for availability or sales.
- On mobile, keep product details and purchase actions visible without covering size selection.
