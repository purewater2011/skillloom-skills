# Style guide: Clay Ledger

Calm, editorial warmth balances a deep ink canvas with tactile clay neutrals and precise teal data accents.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #171815 | ground |
| `--surface` | #282923 | cards and panels |
| `--fg` | #F5F3EA | primary text |
| `--muted` | #C2C2B5 | secondary text |
| `--accent` | #63C6B0 | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #D6A77A | supporting color, used sparingly |
| `--rule` | #55564B | hairlines and borders |

## Type

- Display: condensed stack, weight 800, uppercase, normal tracking, regular scale.
- Body: sans stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 14px; borders: hairline; shadows: none.
- Background motif: blocks. Density: balanced.

## Rules

- Use a near-black canvas and warm off-white text; keep primary and muted text contrast accessible.
- Set headings in uppercase condensed type at 800 weight; keep them to six words or fewer.
- Build the calendar from equal-sized square day cells in a seven-day weekly grid.
- Use teal intensity steps for activity; distinguish zero activity with a muted clay surface.
- Keep the chart legend, date range, and weekday labels aligned to the grid.
- Use hairline warm-gray borders and 14px corners only on the chart's outer container.
- Avoid gradients, shadows, decorative illustrations, and accent colors outside teal and clay.
