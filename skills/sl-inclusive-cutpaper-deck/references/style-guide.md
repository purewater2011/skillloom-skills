# Style guide: Common Ground Cutpaper

An optimistic editorial workshop aesthetic gives diverse perspectives room to be seen while keeping executive evidence easy to scan.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #FAF7F0 | ground |
| `--surface` | #FFFFFF | cards and panels |
| `--fg` | #192B2B | primary text |
| `--muted` | #485452 | secondary text |
| `--accent` | #9B263B | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #176B69 | supporting color, used sparingly |
| `--rule` | #B4B9AE | hairlines and borders |

## Type

- Display: rounded stack, weight 800, normal tracking, regular scale.
- Body: rounded stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: pill (fully rounded buttons, inputs and tags; 28px on cards and panels so text never escapes a curve); borders: hairline; shadows: none.
- Background motif: paper. Density: balanced.

## Rules

- Use the same three-layer paper signature on every slide: warm ground, one offset colored cutout, and one foreground content layer.
- Set each slide headline as a complete action sentence, with no more than two lines at presentation size.
- Limit any slide to two large cutpaper shapes; keep charts, figures, and labels on flat, unobstructed surfaces.
- Use pill shapes for section tabs and short labels only; never place a paragraph inside a pill.
- Crop supplied photos in clean editorial windows; preserve visible subjects and do not imply unverified results.
- Keep body copy at least 20 px and source or caveat text at least 15 px on a 1920 by 1080 slide.
- Use the accent color for the principal takeaway and the supporting color for comparison; do not use color alone to encode a category.
- Repeat tab position, page number placement, and paper-layer order throughout the deck.
