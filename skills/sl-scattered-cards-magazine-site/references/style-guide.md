# Style guide: Offset Edition

An independent magazine with a lively front page and calm, deliberate reading pages.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #F3F6F5 | ground |
| `--surface` | #FFFFFF | cards and panels |
| `--fg` | #172522 | primary text |
| `--muted` | #40534F | secondary text |
| `--accent` | #A12435 | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #21676A | supporting color, used sparingly |
| `--rule` | #B9C8C3 | hairlines and borders |

## Type

- Display: slab stack, weight 700, normal tracking, regular scale.
- Body: grotesk stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 24px; borders: hairline; shadows: soft.
- Background motif: noise. Density: balanced.

## Rules

- Use at most three slight card rotations in any desktop viewport; keep article text and all mobile cards level.
- Keep every story card's image, headline, category, and date together as one clickable link to its complete article page.
- Keep every topic card together as one clickable link to its topic index; never use a generic top-of-page destination for content links.
- Use a stacked hero composition with reserved space for artwork so artwork never overlaps or obscures either CTA.
- Use the 24px radius on story cards only; navigation, article images, and section boundaries stay unframed.
- Apply fine noise to broad paper areas at low opacity, never over body text or photographs.
- Set article bodies in a single column no wider than 70 characters, with clear subheads and image captions.
- Use the red accent for active links and editorial labels; use the teal accent for topic navigation.
