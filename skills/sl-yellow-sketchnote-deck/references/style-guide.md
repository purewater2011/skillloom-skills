# Style guide: Yellow Ink Notes

Bright, confident, and editorial, using yellow annotation energy to make complex teaching ideas feel immediate and memorable.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #F4F6F8 | ground |
| `--surface` | #FFFFFF | cards and panels |
| `--fg` | #141414 | primary text |
| `--muted` | #4A4F57 | secondary text |
| `--accent` | #9A6B00 | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #F0C84B | supporting color, used sparingly |
| `--rule` | #B9C0C9 | hairlines and borders |

## Type

- Display: didone stack, weight 700, tight tracking, oversized scale.
- Body: grotesk stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 24px; borders: hairline; shadows: soft.
- Background motif: noise. Density: balanced.

## Rules

- Use mustard yellow as a deliberate annotation color, never as a full paragraph color or low-contrast body text.
- Set action titles in a large didone face with tight tracking; keep each title to one clear sentence.
- Add one black-ink sketchnote gesture per slide, such as an underline, arrow, bracket, circle, or hand-drawn divider.
- Keep body copy in grotesk with short lines, generous spacing, and no more than five bullets in a content block.
- Use imperfect-looking strokes while keeping alignment, spacing, and baseline rhythm precise enough for professional delivery.
- Reserve pale yellow fills for emphasis panels and use black outlines for diagrams, labels, and key callouts.
- Build visual progression from problem to method to evidence to action; do not treat slides as disconnected posters.
