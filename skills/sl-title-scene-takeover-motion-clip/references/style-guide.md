# Style guide: Gridline Takeover

A composed editorial title enters with measured confidence against a saturated ground, using space and timing as the main visual effects.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #123B3A | ground |
| `--surface` | #1B514D | cards and panels |
| `--fg` | #FFFDF5 | primary text |
| `--muted` | #D4E8DF | secondary text |
| `--accent` | #F5C84B | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #E97855 | supporting color, used sparingly |
| `--rule` | #75A49A | hairlines and borders |

## Type

- Display: didone stack, weight 700, uppercase, tight tracking, oversized scale.
- Body: grotesk stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 8px; borders: hairline; shadows: none.
- Background motif: grid. Density: airy.

## Rules

- Set the main title in uppercase didone with a strong editorial contrast and no more than six words.
- Keep the title aligned to a visible grid edge; never center every element by default.
- Use the saturated ground as the dominant field and reserve the yellow accent for one focal motion cue.
- Keep supporting copy in grotesk, short, quiet, and at least two steps smaller than the title.
- Animate one focused takeover action per scene: reveal, slide, crop, or underline, never several at once.
- Leave generous negative space around the title so the frame remains legible on mobile crops.
- Use hairline grid rules sparingly and keep corner radii at 8px for any framed element.
