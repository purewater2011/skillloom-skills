# Style guide: Four-Surface Chorus

Precise and propulsive, with each repeated prompt revealing a new piece of visible progress.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #101214 | ground |
| `--surface` | #20272A | cards and panels |
| `--fg` | #F7F8F5 | primary text |
| `--muted` | #BDC9C8 | secondary text |
| `--accent` | #E6F26B | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #6CE1CF | supporting color, used sparingly |
| `--rule` | #667276 | hairlines and borders |

## Type

- Display: didone stack, weight 700, normal tracking, regular scale.
- Body: grotesk stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 14px; borders: hairline; shadows: none.
- Background motif: blocks. Density: balanced.

## Rules

- Use exactly four product-surface beats in the order capture, plan, build, publish.
- Repeat the same short monospace prompt on each surface beat; keep its spelling and position identical.
- Cut directly between scenes; do not use fades, dissolves, wipes, or simulated camera moves.
- Give each surface one accent block that advances to the next quadrant on the following beat.
- Set display headlines in didone at 700 weight and limit each to six words.
- Keep product-interface rows to four or fewer per shot and large enough to read at phone width.
- Show proof through supplied artifacts or clearly labeled illustrative states; never invent performance figures or testimonials.
