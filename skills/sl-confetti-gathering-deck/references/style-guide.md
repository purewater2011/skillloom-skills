# Style guide: Confetti Gathering

A dark editorial canvas becomes a festive paper gathering through slanted serif headlines, tactile cut-paper shapes, and controlled bursts of color.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #101014 | ground |
| `--surface` | #222228 | cards and panels |
| `--fg` | #FFFFFF | primary text |
| `--muted` | #C5C5CC | secondary text |
| `--accent` | #FFD447 | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #FF725E | supporting color, used sparingly |
| `--rule` | #55545C | hairlines and borders |

## Type

- Display: serif stack, weight 800, tight tracking, oversized scale.
- Body: serif stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 14px; borders: hairline; shadows: hard.
- Background motif: paper. Density: balanced.

## Rules

- Set every headline in a bold editorial serif and slant its paper-backed text panel by 3 to 7 degrees.
- Keep headline wording exact and use complete action-oriented sentences, except for the quote layout.
- Use ink as the ground on most slides; reserve bright paper colors for focal shapes, labels, and chart emphasis.
- Limit each slide to three confetti colors chosen from yellow, coral, cyan, and leaf green.
- Build confetti from crisp paper-cut circles, bars, triangles, and torn-edge blocks; keep pieces away from text.
- Use serif body copy with clear line spacing and short readable lines; never place small text over a busy motif.
- Repeat one small registration mark or paper-corner detail across slides to make the deck feel like one event series.
