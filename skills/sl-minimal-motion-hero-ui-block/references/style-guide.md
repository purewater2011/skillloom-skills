# Style guide: Quiet Kinetic

Calm and human editorial typography meets a saturated teal canvas, with subtle motion that gives the hero a considered sense of life.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #00534D | ground |
| `--surface` | #17645D | cards and panels |
| `--fg` | #F6F0E5 | primary text |
| `--muted` | #D7E4DC | secondary text |
| `--accent` | #F0B77A | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #B6D7CA | supporting color, used sparingly |
| `--rule` | #6F9B91 | hairlines and borders |

## Type

- Display: serif stack, weight 600, normal tracking, oversized scale.
- Body: serif stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 8px; borders: hairline; shadows: none.
- Background motif: grid. Density: airy.

## Rules

- Use a saturated teal ground across the full hero; reserve cream for the text panel and small controls.
- Set the headline in system serif, sentence case, at no more than 8 words.
- Keep supporting copy to two concise sentences and a readable line length.
- Use one warm clay or apricot accent for the primary action; never compete with it using a second CTA color.
- Animate only a small decorative grid or product detail; keep motion slow, subtle, and reduced-motion aware.
- Use an 8px maximum corner radius and hairline rules; avoid pills, heavy shadows, and floating-card stacks.
- Maintain strong text contrast on both teal and cream surfaces; use muted text only where it still reads clearly.
