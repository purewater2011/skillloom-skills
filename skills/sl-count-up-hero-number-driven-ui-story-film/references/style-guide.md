# Style guide: Countline Editorial

Crisp editorial optimism with a high-contrast product interface and one insistent number driving the story.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #FFFFFF | ground |
| `--surface` | #F0F0F0 | cards and panels |
| `--fg` | #080808 | primary text |
| `--muted` | #4A4A4A | secondary text |
| `--accent` | #D9482B | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #A83220 | supporting color, used sparingly |
| `--rule` | #080808 | hairlines and borders |

## Type

- Display: condensed stack, weight 900, uppercase, tight tracking, oversized scale.
- Body: sans stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: 0px; borders: bold; shadows: none.
- Background motif: lines. Density: balanced.

## Rules

- Set the main count in uppercase condensed at 900 weight and make it the largest element in every counter scene.
- Keep the canvas pure white with black type, black interface panels, and exactly one warm red accent.
- Use thin horizontal rules and directional cursor trails to connect scenes; never use decorative blobs or gradients.
- Keep headlines to six words or fewer and pair them with short editorial serif answer lines when explanation is needed.
- Show interface chrome in near-black rectangles with white labels, compact spacing, and no rounded corners.
- Animate the cursor as a purposeful operator that selects, confirms, and advances; never let it drift without a task.
- Reserve the final scene for a quiet end card with the product name, one outcome line, and generous white space.
