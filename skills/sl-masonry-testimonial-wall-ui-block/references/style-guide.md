# Style guide: Paper Current

Warm paper tones and quiet teal give varied customer voices an editorial rhythm without making the section feel decorative or overly polished.

## Tokens

| Token | Value | Use |
|---|---|---|
| `--bg` | #f5f0e6 | ground |
| `--surface` | #fffdf8 | cards and panels |
| `--fg` | #282922 | primary text |
| `--muted` | #57584f | secondary text |
| `--accent` | #176b61 | the one strong color: key words, primary action, one highlight per view |
| `--accent-2` | #b9d8ca | supporting color, used sparingly |
| `--rule` | #c9c2b5 | hairlines and borders |

## Type

- Display: mono stack, weight 700, normal tracking, regular scale.
- Body: sans stack. System fonts only; never load webfonts.

## Shape and texture

- Corner radius: pill (fully rounded buttons, inputs and tags; 28px on cards and panels so text never escapes a curve); borders: hairline; shadows: soft.
- Background motif: paper. Density: balanced.

## Rules

- Use a warm off-white canvas and near-white quote surfaces; keep the contrast between them subtle.
- Use deep teal only for small labels, quote marks, or one compact emphasis per card.
- Set the section heading in a system monospace face; keep quote copy in a readable system sans face.
- Vary card heights through quote length, not arbitrary empty space or decorative filler.
- Use a two-column masonry rhythm on desktop and a single ordered column on narrow screens.
- Keep each quote to one clear idea and show the speaker name and role directly beneath it.
- Use thin warm-gray borders; avoid heavy shadows, gradients, and high-saturation fills.
